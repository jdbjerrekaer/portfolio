## Recruiter takeaway

Cramer is the AI assistant Adtraction's own staff use to ask questions about brands, partners and sales. The AAMP team built the agent, the backend and the first chat page. Over two days in October 2026 I rebuilt that chat page on Adtraction's UI toolkit, so it looks and behaves like the rest of the platform: the side nav, chat lists, messages, thinking steps, tables, ask cards, the composer and a My files pane. The demo below runs my code, not a recording or a lookalike. Only the data is fake, and the answers are scripted replays.

**All names and numbers in this demo are mock data.**

## What Cramer is

Account managers and sales staff ask Cramer things like "why did this brand's EPC drop last week?" or "put September's partner results in a table". It runs queries, can ask a follow-up question when the request is ambiguous, and answers with text, tables and small toolkit components such as stats badges and info boxes. Scheduled prompts run on their own and land in their own chats.

**About the data:** every brand, channel, partner, person, chat, file and number in the demo is invented for this page. None of it is real Adtraction data or describes a real customer, and the answers are scripted, not generated by the real assistant.

The agent, its tools, the backend and the prompts are the work of the AAMP team. This case study is only about the interface. In the demo, a small script in the page stands in for the backend and replays scripted answers, so it says the same kind of thing whatever you type. Try asking for a table, asking it to ask you something, naming a brand, or asking for a draft.

My part was 17 commits on one branch: the chat page itself (a large vanilla HTML page) and the React islands mounted into it. I worked from the toolkit's design system and wrote down the app-specific rules in a DESIGN.md next to the code.

## Side nav and peek

The side nav mirrors the platform's partner side menu: the same nav item styling, collapse behaviour and logo. Collapsing it leaves a 72px icon rail. When the chat list is hidden, holding the pointer on Chat or Schedules for 400ms peeks the list in a popover, so you can jump to another chat without opening the column again. Picking a row from the peek makes that list the active nav item. Between 769 and 1180px wide the nav switches to the icon rail on its own, and the account button opens a popover with the Dark mode choice and Logout.

## Chat lists

Chats and schedules use the toolkit's list items, with sticky Pinned and Recent headers that cover the scroll padding above them so no row shows through. Every row with a menu gets the same items on right-click and from the keyboard. Search runs over titles and message text.

## Messages and thinking steps

Cramer's answers carry its avatar and an author row. While it works, its steps stream into one light grey container: plain-language labels instead of tool names, toolkit loaders and tags for status, and SQL on a white surface. When the answer starts, the steps fold into a "Worked for …" summary you can open again.

Brand, channel and partner names in an answer render as the toolkit's own name components, so they look and behave like they do on the platform.

## Tables and embeds

Markdown tables render as the toolkit table, with Copy table and full screen in a toolbar that drops to icon buttons when narrow. Below 1024px, where the toolkit hides its own full screen, a toolkit modal takes over.

Cramer can also place a few toolkit components in an answer, from a fixed allow-list. Word-sized ones like a stats badge join the end of the sentence before them instead of taking a row of their own.

## Ask cards and feedback

When a question is ambiguous, Cramer asks before it answers. The ask card is built from toolkit radios, list items and buttons, and collapses to a read-only summary once answered. Under each answer, a feedback bar offers copy, thumbs up and thumbs down. Thumbs down opens a panel of short tags and a text field.

## Composer and skills menu

One "+" button opens a menu with file upload and the skills, grouped by category with sticky headers and a scroll shadow. The placeholder types out topics in a new chat and suggests follow-ups after a pause in an existing one. A ring next to Send shows how much of the context window the chat has used.

## My files pane

Charts Cramer made and files you uploaded live in a My files pane, with image previews, a download button on each tile and a right-click menu. The pane is resizable with the same pill handle as the toolkit's side panels: it follows the pointer, rubber-bands past its limits, works with the arrow keys and resets on double-click.

## Motion and reduced motion

Motion follows the toolkit's durations and easing, and animates only opacity, transform and filter. Every animation has a reduced-motion path: the side nav width, the file pane handle, scroll to latest, thinking steps, message actions and the avatar.

## The playful avatar

The avatar is the one playful element in the app, on purpose. Click or drag it and it reacts with a short quip, one bubble at a time. Everything else stays calm.
